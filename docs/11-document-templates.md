# 11 — 内置文档模板（0.7.0）

> 日期：2026-09-16。范围仅为新建普通文本文件；不提供已有正文写回、自定义脚本或模板插件。

## 1. 使用方式

新建文档 → 选择文档库和现有子目录 → 输入文件名 → 选择模板 → 查看只读预览 → 创建。

| ID | 名称 | 建议扩展名 |
|---|---|---|
| blank | 空白 | .txt |
| meeting | 会议纪要 | .md |
| daily | 每日记录 | .md |
| troubleshooting | 问题排查 | .md |

扩展名仍由文档库规则决定，非空模板也能保存为`.txt`。切换模板不覆盖已手动输入的文件名。旧调用省略模板ID仍创建零字节空文件。

## 2. 渲染边界

- 定义在代码内不可变登记，不从用户路径、网络或数据库加载。
- 仅支持`{{title}}`、`{{date}}`、`{{datetime}}`，不使用eval、表达式、属性访问或动态代码。
- 标题来自最终文件名去掉扩展名；只替换一次，标题中的`{{date}}`等保持字面值。
- 非空模板标题最多255个Unicode字符，拒绝空白标题、控制符、代理字符、BOM、换行和显式双向控制符；保留合法组合字符、ZWJ与变体选择符，不静默规范化。
- 一个带时区时间快照生成本次全部日期/时间。预览和创建是两次独立操作，创建时重新取时间；界面明确解释二者可能不同。
- 输出为严格UTF-8、LF、无开头BOM，最多65536字节。文件层独立复验，不依赖GUI或渲染器已经验证过。

## 3. 新建文件安全

1. 先纯校验文件名与全部内容，严格编码完成后才尝试新建。
2. 再遵守既有本地固定NTFS、库内现有目录、非重解析路径、扩展名和排除规则。
3. 以`O_CREAT | O_EXCL`排他创建，已有同名文件不覆盖、不追加、不自动改名。
4. 检查短写、刷新和fsync，并验证关闭与最终文件元信息；然后走既有登记及索引。
5. 文件层创建成功后的任何错误或取消都保留文件，返回`created_partial`及路径；服务请求补偿扫描，不重复执行创建。界面不自动打开编辑器。
6. 用户自行检查保留文件；管理信息备份仍不包含正文，模板不改变该边界。

文件名组件上限按Windows UTF-16单元计数，非BMP字符占两个单元；同时拒绝保留设备名和不合法字符。

排除目录在访问/创建之前按组件校验，手动输入也不能绕过。目录输入不去掉前导空格，选择的` folder`不会变为另一个`folder`目标。

文件已经成功写入但管理登记失败，返回`created_not_registered`；已经登记后索引或状态刷新抛错，返回`created_followup_failed`。两者都显示保留路径，不提示重复创建；即使补偿扫描调度失败，也不能掩盖已创建的事实。

这不是跨文件系统和数据库的原子事务，也不宣称断电时一定保存完整正文。部分结果明确可见优先于错误后删除文件。

## 4. 异步与接口

- `list_templates`返回冻结描述元组，`preview_template`返回冻结预览DTO，二者不创建文件。
- 模板预览走预览执行器，不在整库写扫描后等待，也不取消主文档预览。
- GUI防抖200ms，按请求代际、当前输入与窗口生命周期检查结果；只在有效预览成功后允许提交。
- GUI只传模板ID和正常新建参数，不回传预览正文。服务在写命令中重新校验和渲染。
- 成功新建才可另发编辑器打开请求；部分创建错误只提示并刷新查询。

完整命令签名见[实现协作契约](08-implementation-contracts.md)。

## 5. 验证口径

- 纯渲染：固定时区和日期、未知变量/ID、Unicode、占位符不递归、不可变定义、UTF-8大小及空白模板。
- 文件层：重名原文hash不变、真实线程竞争、创建前后取消、短写/flush/fsync/fdopen/关闭/元信息故障均不删除已创建文件。
- 服务：预览不创建、创建时跨日重渲染、内容立即可检索、未指定模板兼容、排除目录拒绝、部分失败只安排补扫不再次写，登记/索引/状态/补扫故障不误报未创建。
- 隐藏GUI：快速切换和迟到回调、编辑过的文件名不覆盖、扩展名规则、前导空格目录保持、实际服务与隔离文件集成；编辑器用mock，不操作用户编辑器。
- 冻结包自测包含真实模板文件创建、UTF-8/LF及全文索引检查；完整数量和发行结果见[迭代日志](09-iteration-log.md)。
